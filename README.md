# Data-analysis-dashboard
I developed an interactive Excel dashboard to analyze sales executives’ performance across different cities, track key sales KPIs and generate actionable business insights using Pivot Tables, charts, and slicers.
## Project Title
Interactive Sales Performance Dashboard using Excel
## Project Objective
To analyze sales data and create an interactive dashboard that evaluates individual performance, monitors target achievement, and provides actionable insights for improving sales strategy. 
## Dataset used
<a href= "https://github.com/analyst-vani/Data-analysis-dashboard/blob/main/Raw%20Data.xlsx">Data set</a>
## Question KPIs
-	What are the total sales generated by the team?
-	Which sales executive generated the highest sales?
-	Who are the top 3 performing sales executives?
-	Which sales executive generated the lowest sales?
-	Which city has the highest sales performance?
-	Which city has the lowest sales performance?
-	Which city has the lowest target achievement?
-	Which city has the lowest target achievement?

## Process
-	Collected and organized the sales dataset containing sales executives, sales values, target achievement %, and city information.
-	Cleaned and structured the data in Microsoft Excel for accurate analysis.
-	Created Pivot Tables to summarize sales performance and calculate key metrics.
-	Built Pivot Charts and KPI visuals to analyze sales performance and target achievement.
-	Added Slicers to make the dashboard interactive and enable dynamic analysis.
